## 概述

NexusMind 內建多個研究引擎，可並行查詢、自動融合來自不同來源的證據，產出結構化研究報告。

## 可用引擎

### Google Search（內建）

| 項目 | 值 |
|------|-----|
| 需要 API Key | 否（透過 AI SDK 內建） |
| 觸發方式 | AI 自動判斷需要時呼叫 |
| 限制 | 每次對話最多 5 步工具呼叫 |

適合快速事實查詢和即時資訊檢索。

### Perplexity Sonar Pro

| 項目 | 值 |
|------|-----|
| 環境變數 | `PERPLEXITY_API_KEY` |
| 模型 | `sonar-pro` |
| API 格式 | OpenAI 相容 |
| 特色 | 一次呼叫完成搜尋 + 分析 + 報告 |

系統提示會要求 Perplexity 產出：
- 深度分析（非淺層摘要）
- 5 節結構化報告
- 資料密集（每個論點至少 2 個數據佐證）
- 案例佐證（至少 5 個具體案例）
- 時效性優先（優先引用最新資料）

### Manus AI Agent

| 項目 | 值 |
|------|-----|
| 環境變數 | `MANUS_API_KEY` |
| Agent 版本 | `manus-1.6` |
| API 端點 | `https://api.manus.ai/v1` |
| 執行方式 | 非同步任務（輪詢狀態） |

**執行流程：**

```
1. POST /tasks → 建立研究任務（回傳 task_id）
2. 每 5 秒 GET /tasks/\{task_id\} 輪詢狀態
3. 狀態：pending → running → completed / failed
4. 最大等待時間：5 分鐘（300 秒）
5. 提取報告（優先從輸出檔案，其次從回應文字）
```

**報告提取優先順序：**
1. 從 `output_file`（text/markdown 格式）下載完整報告
2. 若無文件，取 `output_text`（需長度 > 200 字且含 Markdown 標題）
3. Fallback：合併最後一條訊息內容

### Deep Research（Mastra Workflow）

| 項目 | 值 |
|------|-----|
| 需要 API Key | 否（使用 Gemini） |
| 執行方式 | 多步驟工作流程 |
| 特色 | 自動分解問題、逐步研究、綜合分析 |

## 使用方式

1. 進入 **Research** 頁面
2. 輸入研究主題（例如：「2025 年 AI Agent 市場趨勢分析」）
3. 選擇要使用的引擎（可多選並行）
4. AI 會自動分解問題、並行查詢、融合結果

## 並行研究

選擇多個引擎時，NexusMind 會：

1. **同時發送** — 向所有選擇的引擎並行發出查詢
2. **獨立執行** — 各引擎獨立完成研究
3. **融合證據** — 自動整合不同來源的發現
4. **衝突標註** — 標明不同引擎之間證據的矛盾
5. **綜合報告** — 產出結構化的最終研究報告

## 報告格式

所有引擎產出的報告遵循統一結構：

1. **執行摘要**（300-500 字）
2. **5 個主要章節**（各 400-800 字）
3. **結論與建議**（5-7 條可行動建議）

品質要求：
- 每個論點至少 2 個數據佐證
- 至少 5 個具體案例
- 優先引用最新資料

## 研究報告管理

| 操作 | API 端點 |
|------|---------|
| 列出研究報告 | `GET /api/research` |
| 查看報告內容 | `GET /api/research/:id` |
| 建立新研究 | `POST /api/research` |
| 刪除報告 | `DELETE /api/research/:id` |
