## 概述

NexusMind 內建多個研究引擎，可以並行查詢、融合證據、解決衝突，提供最全面的研究結果。

## 可用引擎

| 引擎 | 說明 | 需要 API Key |
|------|------|-------------|
| **Google Search** | 免費網路搜尋 | 否 |
| **Perplexity** | AI 增強即時搜尋 | 是 |
| **Manus** | 深度長篇研究 | 是 |
| **Deep Research** | Mastra workflow 多步驟推理 | 否 |

## 使用方式

1. 進入 **Research** 頁面
2. 輸入研究主題
3. 選擇要使用的引擎（可多選）
4. AI 會自動分解問題、並行查詢、融合結果

## 並行研究

選擇多個引擎時，NexusMind 會：

- 同時向所有引擎發送查詢
- 自動融合不同來源的證據
- 標註證據之間的衝突
- 產出綜合研究報告

## 問題分解器

複雜的研究問題會被自動分解為多個子問題，分別查詢後再綜合，確保研究的全面性。
