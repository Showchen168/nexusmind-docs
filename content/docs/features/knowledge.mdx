## 概述

知識管理是 NexusMind 的基礎。你可以上傳各種格式的文件，AI 會自動解析內容、建立向量嵌入、並在知識圖譜中建立實體關係。

## 支援的上傳格式

| 格式 | 解析方式 | 說明 |
|------|----------|------|
| **PDF** | Marker 微服務 | 支援文字型與圖片型（Gemini Vision OCR） |
| **DOCX** | Marker 微服務 | Word 文件 |
| **PPTX** | Marker 微服務 | PowerPoint 簡報 |
| **XLSX** | Marker 微服務 | Excel 試算表 |
| **TXT** | 原生解析 | 純文字檔案 |

## 上傳文件

1. 進入 **Knowledge** 頁面
2. 點擊「上傳」按鈕，選擇檔案（支援批次上傳）
3. 系統自動完成以下處理：
   - 透過 Marker 微服務解析文件內容
   - 產生向量嵌入儲存至 pgvector
   - 在 LightRAG 建立知識圖譜實體

## YouTube 整合

除了檔案，NexusMind 還能自動擷取 YouTube 內容：

- **單一影片**：貼上 YouTube 連結，自動解析字幕
- **播放清單**：貼上播放清單連結，批次導入所有影片字幕
- **頻道**：輸入頻道 ID，自動爬取最新影片

## URL 爬取

貼上任何網頁 URL，NexusMind 會自動擷取網頁內容並嵌入到知識庫。

## 知識圖譜

基於 LightRAG GraphRAG 技術，自動從文件中提取實體與關係，以 Cytoscape 視覺化呈現：

- 瀏覽文件之間的關聯
- 點擊節點查看相關文件
- 探索概念之間的連結

## 監控源（自動更新）

設定知識源後，系統每小時自動檢查更新：

- **RSS Feed**：自動擷取新文章
- **網頁 URL**：監控內容變化
- **YouTube 頻道**：自動導入新影片

```bash title="設定定時任務"
crontab -e
# 每小時檢查知識源更新
0 * * * * curl -s -H "Authorization: Bearer $CRON_SECRET" \
  http://localhost:3001/api/cron/check-sources
```

## 文件版本控制

每次文件更新時，系統會自動保存歷史版本：

- 瀏覽特定文件的所有歷史版本
- 比較不同版本之間的差異
- 一鍵還原到任何歷史版本
