## 概述

Canvas 是 NexusMind 的富文本編輯器，基於 TipTap (ProseMirror) 建構，內建 AI Copilot 寫作輔助。

## AI Copilot 寫作助手

### Ghost Text 智慧補全

當你正在打字時，AI 會自動在游標後方顯示建議的續寫內容（灰色文字）：

- 按 **Tab** 接受補全
- 按 **Esc** 取消
- 按 **Cmd/Ctrl + J** 手動觸發

### @mention 智慧引用

在編輯器中輸入 `@`，可以搜尋並引用知識庫中的文件，AI 會基於引用的內容提供更精準的寫作建議。

### AI 指令

在編輯器中輸入 `/` 可以觸發快速指令：

| 指令 | 功能 |
|------|------|
| `/expand` | 擴展選取的內容 |
| `/shorten` | 縮短選取的內容 |
| `/tone` | 調整語氣風格 |

## 快捷鍵

| 功能 | Mac | Windows |
|------|-----|---------|
| AI 補全 | `Cmd+J` | `Ctrl+J` |
| 接受補全 | `Tab` | `Tab` |
| 取消補全 | `Esc` | `Esc` |
| 智慧引用 | `@` | `@` |
| AI 指令 | `/` | `/` |

## 圖表生成

NexusMind 支援兩種圖表：

- **Recharts** — 統計圖表（長條圖、折線圖、圓餅圖等）
- **Cytoscape** — 拓撲圖 / 關係圖

## 報告匯出

富文本內容可以匯出為：

- **DOCX** — Word 文件（docx v9）
- **PDF** — PDF 文件

## Google Drive 匯入

透過 Rube MCP 整合，可以直接從 Google Drive 匯入文件到 Canvas 中編輯。
