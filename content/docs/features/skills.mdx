## 概述

技能系統讓 AI 不只能回答問題，還能實際執行程式碼並產出各種格式的文件。所有程式碼都在 Docker 容器中安全執行。

## 三階段執行流程

### 階段 1：意圖判斷

AI 分析你的需求，判斷需要哪些資源和工具。如果需求不夠清楚，會先向你提問釐清。

### 階段 2：研究員

AI 從知識庫（RAG）和網路搜尋收集相關資料，為執行做準備。

### 階段 3：工程師

AI 產生程式碼並在 Docker 沙箱中執行，輸出最終結果。

## 支援的執行語言

- **JavaScript** — Node.js 環境
- **Python** — Python 3 環境

## 輸出格式

| 格式 | 說明 |
|------|------|
| **DOCX** | Word 文件 |
| **PDF** | PDF 文件 |
| **PNG** | 圖片 |
| **JSON** | 結構化資料 |

## AI 生成技能

你可以透過自然語言描述你想要的技能，AI 會自動建立新的技能模板，之後可以重複使用。

## 進度動畫

技能執行時會顯示 Claude Code 風格的 6 階段進度展示，讓你清楚知道目前執行到哪個步驟。
