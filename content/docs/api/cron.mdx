## `/api/cron/check-sources`

### GET

`maxDuration: 300s`

Cron Endpoint — 定期檢查到期的知識庫監控源  * NAS Task Scheduler 每小時 curl 觸發：   curl -H "Authorization: Bearer $CRON_SECRET" \        http://localhost:3000/api/cron/check-sources /

**請求範例**

```bash
curl /api/cron/check-sources
```
