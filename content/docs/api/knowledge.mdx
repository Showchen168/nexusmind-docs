## `/api/knowledge`

### GET

`需要認證`

取得使用者的所有文件

**請求範例**

```bash
curl /api/knowledge
```

### POST

`需要認證`

建立新文件

**Request Body**

| 欄位 | 類型 | 必填 | 說明 |
|------|------|------|------|
| `title` | `string` | 是 | - |
| `content` | `string` | 是 | - |
| `tags` | `string[]` | 否 | - |

**請求範例**

```bash
curl -X POST /api/knowledge \
  -H "Content-Type: application/json" \
  -d '{"title":"...","content":"...","tags":"value"}'
```
