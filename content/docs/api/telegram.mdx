## `/api/telegram/bot`

### GET

`需要認證`

GET /api/telegram/bot
讀取 Bot 設定（Token 遮罩化）+ Webhook 狀態

Per-user 擁有權檢查：
- 若 Bot config 的 configured_by != 當前使用者 → 自動清除舊設定 + 舊綁定
- 新使用者看到乾淨的初始狀態

**請求範例**

```bash
curl /api/telegram/bot
```

### POST

`需要認證`

POST /api/telegram/bot
驗證並儲存 Bot Token
Body: \{ token: string \}

**請求範例**

```bash
curl -X POST /api/telegram/bot
```

### DELETE

`需要認證`

DELETE /api/telegram/bot
刪除 Bot 設定

**請求範例**

```bash
curl -X DELETE /api/telegram/bot
```

## `/api/telegram/bot/webhook`

### POST

`需要認證`

POST /api/telegram/bot/webhook

Body: \{ webhookUrl?: string \}
若未提供 webhookUrl，自動從 request headers 推斷

**請求範例**

```bash
curl -X POST /api/telegram/bot/webhook
```

### DELETE

`需要認證`

DELETE /api/telegram/bot/webhook

**請求範例**

```bash

```

## `/api/telegram/webhook`

### POST

`需要認證` `maxDuration: 120s`

**Request Body**

| 欄位 | 類型 | 必填 | 說明 |
|------|------|------|------|
| `(Zod schema)` | `object` | 是 | Validated by Zod schema |

**請求範例**

```bash

```
